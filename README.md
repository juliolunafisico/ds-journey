# Data Science Journey

Personal roadmap documenting my transition from Physics Engineering 
to Scientific Data Scientist.

## Background
Physics Engineering graduate (UACH), iGEM 2025 gold medalist. 
Strong foundation in mathematics, Python, and MATLAB.

## Goal
Remote work as a Scientific Data Scientist, specializing in 
computational physics and numerical simulation.

## Structure
This repository tracks progress through a 10-month study plan built 
around the IBM Data Science Professional Certificate, Google Advanced 
Data Analytics, the Deep Learning Specialization, and an applied 
mathematics reading track.

- `certificates/` — coursework and notes per Coursera certificate
- `projects/` — portfolio projects (exploratory analysis, ML pipeline, 
  physics simulation, SQL + business analysis)
- `math-notes/` — notes from the applied mathematics reading track
- `kaggle/` — competition work and targeted skill reinforcement
